A machine-learning application for recommending suitable crops from soil
nutrient and environmental measurements. The project uses:

-   **Streamlit** for the user interface.
-   **FastAPI** for the prediction REST API.
-   **Random Forest** as the trained crop classification model from the
    Module 5 project.
-   **Pandas and Joblib** for preparing prediction inputs and loading
    saved model artifacts.

In this architecture, Streamlit collects the user's measurements and
sends them to FastAPI. FastAPI validates the request, runs the trained
model, and returns the recommended crop and the three highest class
probabilities. Streamlit displays the response.

## 1. Create the model artifacts

Run the Module 5 notebook through its final model-saving cell. It should
generate:

-   `crop_recommendation_rf.pkl`
-   `crop_recommendation_metadata.json`

Copy both files into this project's `models/` directory.

The metadata file should contain the feature names in the same order

saved feature order when constructing the prediction DataFrame. The
Streamlit frontend uses the metadata for its training-range warnings.

##  2. Python and environment setup

Python **3.11** is recommended for this project. Python 3.10 may also
work if all installed package versions support it.

You can use your existing Anaconda environment if it already contains
the dependencies for the Module 5 Streamlit application. For example:

``` bash
conda activate crop_recommendation
```

Alternatively, create a dedicated environment:

``` bash
conda create -n crop_recommendation python=3.11 -y
conda activate crop_recommendation
```

Install the project dependencies from the project root:

``` bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

A `requirements.txt` for this combined application should include:

``` text
streamlit
fastapi
uvicorn
pydantic
requests
pandas
numpy
joblib
scikit-learn
pytest
httpx
```

For reproducible deployment, pin package versions after confirming the
versions that work with the saved model.

## 3. Start the FastAPI backend

Open the first terminal, activate the project environment, and navigate
to the project root (the directory containing `app/`, `models/`, and
`tests/`).

``` bash
conda activate crop_recommendation
cd path\to\crop_recommendation
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Keep this terminal open while using the application.

The API loads the saved Random Forest model and metadata from `models/`.
Confirm that the model and metadata paths in `app/main.py` point to:

``` python
BASE_DIR = Path(__file__).resolve().parent.parent

MODEL_PATH = BASE_DIR / "models" / "crop_recommendation_rf.pkl"
METADATA_PATH = BASE_DIR / "models" / "crop_recommendation_metadata.json"
```

## API endpoints

  Method   Endpoint     Purpose
  -------- ------------ -----------------------------------------------------
  `GET`    `/`          Optional API welcome route, if defined in `main.py`
  `GET`    `/health`    Checks API/model availability
  `POST`   `/predict`   Returns a crop prediction
  `GET`    `/docs`      Interactive Swagger API documentation

Open the interactive documentation at <http://127.0.0.1:8000/docs>.

A `404 Not Found` response at `/` is normal if a root route has not been
defined. Use `/health` or `/docs` to verify the service.

## 4. Start the Streamlit frontend

Open a **second terminal**. Activate the same environment and navigate
to the project root:

``` bash
conda activate crop_recommendation
cd path\to\crop_recommendation
streamlit run app/app.py
```

Streamlit normally opens at <http://localhost:8501>.

Both services must be running at the same time:

-   FastAPI backend: `http://127.0.0.1:8000`
-   Streamlit frontend: `http://localhost:8501`

The Streamlit application sends prediction requests to the FastAPI
endpoint:

``` python
API_URL = "http://127.0.0.1:8000/predict"

response = requests.post(
    API_URL,
    json=values,
    timeout=30
)
response.raise_for_status()
result = response.json()
```

Here, `values` is a dictionary containing the seven input fields.
Streamlit should not load or run the Random Forest model directly; model
inference is handled by FastAPI.

If the API is not running or cannot be reached, Streamlit should display
a connection error. Start FastAPI before submitting a prediction.

## 5. Input fields

The prediction request uses the seven features from the Module 5 crop
recommendation model:

  Feature         Description             API validation
  --------------- ----------------------- ---------------------
  `N`             Nitrogen                Non-negative number
  `P`             Phosphorus              Non-negative number
  `K`             Potassium               Non-negative number
  `temperature`   Temperature in °C       Finite number
  `humidity`      Relative humidity (%)   Between 0 and 100
  `ph`            Soil pH                 Between 0 and 14
  `rainfall`      Rainfall in mm          Non-negative number

The API's Pydantic input schema performs request validation. The
Streamlit application also checks that entered values are numeric and
finite and can warn when values fall outside the observed training
ranges stored in the metadata.

## 6. Test a prediction through Swagger UI

1.  Start FastAPI.
2.  Open <http://127.0.0.1:8000/docs>.
3.  Expand `POST /predict` and select **Try it out**.
4.  Enter this example request:

``` json
{
  "N": 90,
  "P": 42,
  "K": 43,
  "temperature": 20.9,
  "humidity": 82.0,
  "ph": 6.5,
  "rainfall": 202.9
}
```

5.  Select **Execute** and inspect the response.

The expected response schema is:

``` json
{
  "predicted_crop": "rice",
  "confidence": 0.9825,
  "top_predictions": [
    {
      "crop": "rice",
      "probability": 0.9825
    },
    {
      "crop": "jute",
      "probability": 0.0105
    },
    {
      "crop": "cotton",
      "probability": 0.004
    }
  ],
  "model_version": "1.0.0"
}
```

The crop names and probabilities above are illustrative. Actual results
depend on the saved model and supplied measurements. The confidence is
the highest predicted class probability; it is not a guarantee of crop
success or necessarily a calibrated real-world probability.

## 7. Run automated API tests

The tests use FastAPI's `TestClient`, so you do **not** need to start
Uvicorn in a separate terminal to run them. The model and metadata files
must still be present because the application loads them when the test
module imports `app.main`.

From the project root, run:

``` bash
python -m pytest -v
```

To run only the API test file:

``` bash
python -m pytest tests/test_api.py -v
```

The test suite should cover:

-   Health endpoint response.
-   Successful prediction with valid input.
-   Rejection of a request with a missing feature.
-   Rejection of humidity outside the allowed range.
-   Rejection of soil pH outside the allowed range.

A successful run should report that all collected tests passed. The
exact test count depends on the tests currently included in
`tests/test_api.py`.

If Python reports `ModuleNotFoundError: No module named 'app'`, check
that:

1.  You are running the command from the project root.
2.  `app/__init__.py` exists.
3.  The project folders match the structure shown above.

Using `python -m pytest -v` from the project root is recommended.

##  8. Troubleshooting

-   **Model or metadata missing:** Run the Module 5 notebook's
    model-saving cell and copy both generated files into `models/`.
-   **API returns `404 Not Found`:** Confirm the URL and route. Use
    `/health` and `/docs`; `/` returns 404 if no root route is defined.
-   **Streamlit cannot connect to FastAPI:** Confirm that Uvicorn is
    running on port `8000` and that `API_URL` in `app/app.py` matches
    the backend address.
-   **Prediction returns `422 Unprocessable Entity`:** Check that all
    seven required fields are present and that values satisfy the
    Pydantic validation rules.
-   **Prediction returns `500`:** Check the FastAPI terminal for the
    underlying model or prediction error. Confirm feature names and
    order match the saved metadata and training process.
-   **`ModuleNotFoundError: No module named 'app'`:** Run tests from the
    project root, ensure `app/__init__.py` exists, and use
    `python -m pytest -v`.
-   **Scikit-learn version warning:** The model was saved with a
    different scikit-learn version from the one currently installed. Use
    the training version where possible, or retrain and resave the model
    in the target environment.
-   **Dependency or test-client warning:** Check installed FastAPI,
    Starlette, HTTPX, and Pydantic versions and use mutually compatible
    versions. A deprecation warning is not necessarily a test failure.

## 9. Responsible use and limitations

##  Dataset Statistics
The Module 5 model was trained on a dataset with 2,200 records and 22
crop classes, as described in the project report. The dataset does not
represent every location, season, soil type, or agronomic factor. It may
not include factors such as soil texture, crop history, pests, and
diseases.

Treat predictions as decision support, not definitive agricultural
advice. Consult local agronomists or agricultural extension
professionals before making planting decisions.

## 10. End-to-end workflow

1.  Train and evaluate the Random Forest model in the Module 5 notebook.
2.  Save the model and metadata into `models/`.
3.  Start FastAPI to load the artifacts and expose the prediction
    endpoint.
4.  Start Streamlit in a separate terminal.
5.  Enter soil and environmental measurements in Streamlit.
6.  Streamlit sends the measurements to FastAPI as a JSON request.
7.  FastAPI validates the request, runs model inference, and returns the
    predicted crop and top three probabilities.
8.  Streamlit displays the API response.
9.  Run automated tests with `python -m pytest -v`.

This separation keeps the user interface independent from the
model-serving API. The same FastAPI prediction service can also be
accessed by other clients, such as a web frontend or mobile application.
